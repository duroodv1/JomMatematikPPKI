Jom Matematik PPKI

Pulihkan paparan aplikasi

Jika skrin kosong atau masih memaparkan versi lama, sambungkan internet dan pulihkan cache aplikasi ini sahaja.

Kemajuan murid tidak dipadam. Tindakan ini tidak mengosongkan LocalStorage, kuki atau data laman lain.

Buka Aplikasi Semula
Masih tidak dapat membuka aplikasi?
  1. Di GitHub, pilih Settings > Pages > Source: GitHub Actions.
  2. Buka Actions > Terbitkan Jom Matematik PPKI > Run workflow pada main.
  3. Pastikan tugas binaan dan penerbitan kedua-duanya berjaya. Laman mesti menggunakan keluaran dist/, bukan kod mentah src/main.tsx.
  4. Tutup tab atau PWA lama, kemudian buka URL daripada keputusan penerbitan. Cuba Chrome, Edge atau Safari yang terkini.

Jika masih gagal, kongsikan URL GitHub Pages dan mesej ralat Console untuk semakan. Jangan kongsikan kata laluan atau token.
